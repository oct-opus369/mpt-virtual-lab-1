# Maximum Power Transfer Theorem – Virtual Lab

Static website (no server needed). Open `index.html` to start; `experiments.html` is the lab home.

## Publish a permanent link with GitHub Pages
1. Create a free account at github.com and click New repository (name it e.g. `mpt-virtual-lab`, set it to Public).
2. Click "uploading an existing file" and drag in ALL files from this folder (not the folder itself), then Commit.
3. Open Settings > Pages. Under Branch choose `main` and `/ (root)`, then Save.
4. After a minute your link appears: `https://<your-username>.github.io/mpt-virtual-lab/`

## Edit before submitting
Search all files for text in [square brackets]: institute name, department, team email, contributors.
In `feedback.js`, replace `YOUR-EMAIL@example.com` with your team email.
