# Maximum Power Transfer Theorem — Virtual Lab

A browser-based educational virtual laboratory for exploring the Maximum Power Transfer Theorem in DC circuits.

## Open the lab

Published site: https://oct-opus369.github.io/mpt-virtual-lab-1/

Start at `index.html` or open `experiments.html` to view the experiment listing.

## Learning path

1. **Aim** — review the objective and learning outcomes.
2. **Theory** — study the Thévenin equivalent, load-power equation and matching condition.
3. **Pretest** — check prerequisite concepts.
4. **Procedure** — follow the experiment steps.
5. **Simulation** — calculate a Thévenin equivalent, vary the load, inspect the graph and record readings.
6. **Posttest** — answer concept and calculation questions.
7. **Lab report** — generate a printable report from recorded readings.
8. **References and contributors** — review learning sources and project credits.
9. **Feedback** — copy feedback text to share with the project team.

## Technical notes

- Built with HTML, CSS and vanilla JavaScript.
- No application server or account sign-in is required.
- Simulation calculations and quiz scoring run in the browser.
- Recorded observations are stored in browser `localStorage`; they remain local to that browser and are not synced between devices.
- The feedback page copies the entered feedback to the clipboard. It does not transmit or email it automatically.
- GitHub Pages hosts the static files.

## Local preview

Download or clone this repository and open `index.html` in a modern browser. For best results, use a local static server or the published GitHub Pages site.
