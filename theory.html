Experiment: Maximum Power Transfer Theorem

Theory

Any linear network seen from two terminals can be replaced by a Thévenin equivalent: a voltage source Vth in series with a resistance Rth. When a load RL is connected, the current is

I = Vth / (Rth + RL)

and the power absorbed by the load is

PL = I²RL = Vth² RL / (Rth + RL)²

Condition for maximum power

Set dPL/dRL = 0:

(Rth + RL)² − 2RL(Rth + RL) = 0  ⇒  RL = Rth

The second derivative is negative at this point, so it is a maximum. The maximum power is

Pmax = Vth² / (4Rth)

Efficiency

Efficiency η = PL / Psource = RL / (Rth + RL). At RL = Rth, η = 50%. Power systems therefore aim for high efficiency, not maximum power; maximum power transfer matters in communication and signal circuits.

AC circuits

For sinusoidal sources, maximum power is delivered when ZL = Zth* (the complex conjugate of the source impedance).

Applications

  • Audio: matching a speaker to an amplifier stage that must deliver as much signal power as possible.
  • Antennas and radio: matching the transmitter, cable and antenna so power is not reflected back.
  • Solar panels: maximum power point tracking sets the operating load so the panel gives its peak output.
  • Sensors and wireless charging, where the little power available matters more than efficiency.

Viva questions

Try answering each one before opening it.

State the maximum power transfer theorem.

A DC source delivers maximum power to a load when the load resistance equals the Thévenin resistance of the source network.

What is the efficiency at maximum power transfer?

50%, because the same current flows through Rth and RL, so half the power is lost inside the source.

Why do power stations not work at maximum power transfer?

They need high efficiency. At the matched condition half the generated power would be wasted.

What happens to load power if RL = 0 or RL → ∞?

It is zero in both cases: at RL = 0 the voltage across the load is zero, and at RL → ∞ the current is zero.

How do you find Rth of a network?

Remove the load, replace independent voltage sources by short circuits and current sources by open circuits, then find the resistance between the load terminals.

What is the condition for AC circuits?

ZL = Zth*, the complex conjugate of the source impedance.
